# Контракты передачи

Принимающая роль проверяет чек-лист. Пункт не выполнен — артефакт
возвращается без доработки, отказ пишется в decisions.md.

## 1. Аудит → продуктовый лид
- [ ] По каждой находке принято решение: чиним сейчас / позже / не чиним
- [ ] Отказы зафиксированы с причиной
- [ ] Блокеры и находки `wellbeing-safety` не отклонены без согласия владельца

## 2. Продуктовый лид → UX и технический лид
- [ ] Проблема как проблема, не как решение
- [ ] Доказательство или пометка ГИПОТЕЗА
- [ ] Измеримый критерий успеха
- [ ] Записаны не-цели
- [ ] Размер S или M

## 3. UX → дизайн и технический лид
- [ ] Основной сценарий по шагам
- [ ] ВСЕ состояния из списка в роли `ux-architect`
- [ ] Поведение при возврате через неделю и через три месяца
- [ ] Уведомления: триггер, текст, действие по нажатию
- [ ] Обратимость каждого действия
- [ ] **Проверка `wellbeing-safety`, если сценарий касается состояния**

## 4. Технический лид → инженеры
- [ ] ADR с минимум двумя вариантами
- [ ] Негативные последствия записаны
- [ ] Ограничения кроссплатформенного фреймворка учтены

## 5. Дизайн → инженеры
- [ ] Все состояния компонента
- [ ] Значения только из токенов
- [ ] Поведение при крупном системном шрифте и 3x длине текста
- [ ] Тёмная тема
- [ ] Расхождения по платформам согласованы

## 6. Инженеры → проверка
- [ ] За фича-флагом
- [ ] Список затронутых экранов
- [ ] Поведение в оффлайне описано
- [ ] Замер холодного старта до и после
- [ ] Разметка событий подключена

## Definition of Done
Работает, измеряется, переживает оффлайн и прерывание, не теряет данные
пользователя, проверено на обеих платформах, доступно, выключается флагом,
и проверено `wellbeing-safety`, если касается состояния.
