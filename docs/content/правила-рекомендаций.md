# Правила рекомендаций: сигнал → карточка «Фокус дня»

Реестр, который `decisions.md` 2026-11-21/22 п.5 поручил создать и который
находка №18 (`findings.md`) назвала конкретным блокером для подключения
`FocusCard` к реальным данным. Этот файл — единственное место, где
принимаются решения о формулировках; при реализации (`FocusCard`,
`HomeScreen.tsx`) брать тексты отсюда один в один, не придумывать новые.

**Не входит в эту задачу (явное решение владельца):** находка №18 того же
цикла, выбор на экране «Поддержка» (`getOnboardingSupportAreas()`, 12
областей). Он сохраняется в `onboardingProfile.ts`, но пока нигде не
читается — подключение к этому реестру осознанно отложено на будущий цикл,
не забыто.

## Легенда: Tier A / Tier B

Протокол `claims-reviewer`, зафиксированный в `decisions.md` 2026-11-21/22
п.5:

- **Tier A** — сон, настроение (самоотчёт), цикл. Доказательная область,
  данные введены самим человеком или посчитаны по его реальным датам.
  Эвристическое сопоставление «сигнал → рекомендация» разрешено напрямую.
- **Tier B** — классический биоритм (физический/эмоциональный/
  интеллектуальный, 23/28/33 дня от даты рождения). Наблюдение модели, не
  факт о состоянии человека. Нельзя триггерить директивную рекомендацию —
  только нейтральное наблюдение, атрибутированное графику/модели («по
  графику», «модель показывает»), не человеку напрямую («у тебя сегодня…»).

**Разрешённые рамки (оба тира):** «может помочь», «стоит попробовать»,
«часто помогает», «traditionally used for». **Запрещено:** «определит»,
«диагностирует», «лечит», «гарантирует», директивное «нужно сделать X».
Полный список — отчёт `claims-reviewer` внутри брифа 001.

**Правило без укора** (тот же дух, что и `decisions.md` 2026-11-21/22 п.2
для отсутствующих источников): низкий сигнал не повод для текста, который
звучит как диагноз или вина. Ни одна формулировка ниже не говорит «у тебя
плохой день» как факт — она либо ссылается на реальный самоотчёт человека,
либо хеджирует вывод модели.

## Источники сигналов (уже существуют в коде, ничего нового не считать)

| Сигнал | Tier | Источник | Как читать |
|---|---|---|---|
| Настроение сегодня | A | `getTodayMood()` (`lib/onboardingProfile.ts`), индексы `MOOD_KEYS` (`i18n/dictionaries/moodOptions.ts`) | `0` = veryBad, `1` = bad, `2` = neutral, `3` = good, `4` = veryGood |
| Короткий сон | A | `sleep` из `getOnboardingSleep()` → `sleepDurationMinutes(sleep)` (`lib/energy.ts`) | минуты сна этой ночи |
| Фаза цикла | A | `getOnboardingCycle()` → `cycleScore(cycle.range, today)` (`lib/energy.ts`), только если `!cycle.notApplicable` | 0–100, низкое значение = около дня начала цикла (менструация и предменструальная фаза) |
| Биоритмы (физ./эмоц./интеллект.) | B | `getBiorhythmValues(birthDate, today)` (`lib/biorhythm.ts`) → `{ physical, emotional, intellect }` | 0–100 каждый, низкое значение = нижняя точка кривой |
| Общий композит | — (смешанный, см. ниже) | `computeEnergy(...).value` (`lib/energy.ts`) | 0–100, среднее по доступным источникам |

Общий композит сам по себе не Tier A и не Tier B — это смесь (всегда
включает Tier B биоритм, иногда Tier A сон/цикл). Поэтому он не
используется для директивных формулировок напрямую, только для сценария
P7 ниже, который сформулирован как наблюдение, не диагноз.

## Пороги (мои решения при составлении реестра — не из кода, помечено явно)

Код не задаёт, что значит «низкое» значение — пороги ниже я определила
сама для этого реестра. Если на реальных данных они окажутся слишком
чувствительными или нечувствительными — это повод вернуться именно сюда,
не в код молча.

- **Настроение низкое:** индекс `0` (veryBad) или `1` (bad).
- **Сон короткий:** `sleepDurationMinutes(sleep) < 420` (меньше 7 часов).
- **Фаза цикла в спаде:** `cycleScore(...) < 35`.
- **Биоритм в спаде (любой из трёх):** значение `< 35`. Проверяется
  независимо для каждого из трёх (`physical`/`emotional`/`intellect`), не
  через `getStandoutCycle` — та функция намеренно берёт только «один самый
  заметный» для короткой строки-инсайта онбординга (другая задача); здесь
  нужно уметь показать несколько слотов одновременно, если несколько
  кривых реально низкие.
- **Общий композит низкий (фоллбек):** `computeEnergy(...).value < 40`.

## Алгоритм выбора трёх карточек

Правило, не псевдокод для выдумывания: пройти сценарии **P1 → P7** по
порядку ниже, собрать те, чьё условие выполняется (с одним исключением —
P5 пропускается, если выполняется условие P1, см. P5). Взять первые **3**
совпавших по этому порядку. Если совпало меньше трёх — дополнить
оставшиеся слоты сценарием **P8 (дефолт)**, по порядку его трёх карточек.
Если не совпало ничего (включая случай, когда `computeEnergy` вернул
`null` — например, нет даты рождения) — показать все три карточки P8, как
сейчас.

```
candidates = []
if (P1.condition) candidates.push(P1)
if (P2.condition) candidates.push(P2)
if (P3.condition) candidates.push(P3)
if (P4.condition) candidates.push(P4)
if (!P1.condition && P5.condition) candidates.push(P5)
if (P6.condition) candidates.push(P6)
if (candidates.length === 0 && P7.condition) candidates.push(P7)

selected = candidates.slice(0, 3)
while (selected.length < 3) {
  selected.push(P8.cards[selected.length])  // Мягкий старт, Планирование, Пространство — по порядку
}
```

(«Условие» P1 означает «настроение сегодня отмечено и оно низкое» — если
настроение сегодня ещё не отмечено, условие P1 ложно, и P5 не блокируется
этим фактом, только настоящим низким настроением.)

## P1 — Настроение сегодня низкое (Tier A, самоотчёт, высший приоритет)

**Условие:** `getTodayMood() === 0 || getTodayMood() === 1`
**Почему первый приоритет:** прямой самоотчёт человека надёжнее любого
расчёта — ровно то, что `decisions.md` 2026-11-21/22 п.5 требует: Tier A
важнее Tier B при конфликте.
**Практика:** «Доброта к себе» (медитация, 6 минут, уже описана в
`docs/content/практики.md`).
**Иконка:** `meditationFigure`

- **RU — заголовок:** Доброта к себе
- **RU — текст:** Ты отметила, что сегодня непросто. Может помочь короткая
  практика «Доброта к себе» (6 минут) — несколько фраз поддержки для себя
  самой, как для близкого человека.
- **EN — title:** Kindness to yourself
- **EN — text:** You marked today as a hard one. The short "Self-kindness"
  practice (6 min) might help — a few supportive phrases for yourself, the
  way you'd speak to someone close.

## P2 — Фаза цикла в спаде (Tier A)

**Условие:** `cycle.range && !cycle.notApplicable && cycleScore(cycle.range, today) < 35`
**Практика:** чай из категории «Тепло и восстановление» (`teaCategories.ts`,
категория 4).
**Иконка:** `kettle`

- **RU — заголовок:** Тепло и забота
- **RU — текст:** По датам цикла сейчас фаза, когда тело часто просит
  больше тепла и мягкости. Стоит попробовать чай из категории «Тепло и
  восстановление» — подойдёт имбирь или куркума.
- **EN — title:** Warmth and care
- **EN — text:** Based on your cycle dates, this is a phase when the body
  often asks for a bit more warmth and gentleness. Worth trying a tea from
  the "Warmth and restoration" category — ginger or turmeric work well.

## P3 — Короткий сон (Tier A)

**Условие:** `sleep && sleepDurationMinutes(sleep) < 420`
**Практика:** «Двойной вдох» (дыхание, 1 минута, физиологический вздох,
уже описан в `docs/content/практики.md`).
**Иконка:** `sleep`

- **RU — заголовок:** Бережный день
- **RU — текст:** Сон сегодня был короче обычного — это не повод себя
  ругать. Можно попробовать «Двойной вдох» (1 минута): быстрый и мягкий
  способ немного прийти в себя.
- **EN — title:** An easier kind of day
- **EN — text:** Sleep was shorter than usual last night — that's not
  something to be hard on yourself about. Worth trying the "Double inhale"
  (1 min): a quick, gentle way to reset a little.

## P4 — Биоритм: физический в спаде (Tier B)

**Условие:** `getBiorhythmValues(birthDate, today).physical < 35`
**Практика:** «Дыхание для возвращения в тело» (уже в приложении, 2
минуты).
**Иконка:** `pulse`
**Формулировка:** атрибутирована графику/модели, не человеку — обязательное
правило Tier B.

- **RU — заголовок:** Телу сегодня легче в покое
- **RU — текст:** По графику биоритмов физическая кривая сейчас ближе к
  нижней точке — это наблюдение модели, не диагноз. Если чувствуется
  напряжение или усталость, может помочь «Дыхание для возвращения в тело»
  (2 минуты).
- **EN — title:** The body may want less today
- **EN — text:** On the biorhythm chart, the physical curve is closer to
  its low point right now — an observation from the model, not a
  diagnosis. If you're noticing tension or fatigue, "Breathing to return to
  the body" (2 min) might help.

## P5 — Биоритм: эмоциональный в спаде (Tier B, только если P1 не сработал)

**Условие:** `!P1.condition && getBiorhythmValues(birthDate, today).emotional < 35`
**Почему подчинён P1:** избегаем показа той же практики («Доброта к себе»)
дважды под двумя разными обоснованиями в один день, и Tier A важнее Tier B
при конфликте на ту же тему.
**Практика:** «Доброта к себе» (та же, что в P1 — применяется только когда
P1 неактивен).
**Иконка:** `meditationFigure`

- **RU — заголовок:** По графику — повод быть к себе мягче
- **RU — текст:** Эмоциональная кривая по классическому расчёту биоритмов
  сейчас ниже обычного — это наблюдение графика, не факт о настроении. На
  всякий случай может помочь практика «Доброта к себе» (6 минут).
- **EN — title:** The chart suggests a little extra softness
- **EN — text:** The emotional curve in the classic biorhythm calculation
  is lower than usual right now — just an observation from the chart, not a
  statement about your mood. The "Self-kindness" practice (6 min) might
  help, just in case.

## P6 — Биоритм: интеллектуальный/фокус в спаде (Tier B)

**Условие:** `getBiorhythmValues(birthDate, today).intellect < 35`
**Практика:** чай из категории «Фокус и ясность» (`teaCategories.ts`,
категория 3) или медитация «Счёт дыхания» (5 минут).
**Иконка:** `idea`

- **RU — заголовок:** Для ясности мыслей
- **RU — текст:** Интеллектуальная кривая по графику биоритмов сейчас ниже
  обычного — наблюдение, не диагноз внимания. Можно попробовать чай из
  категории «Фокус и ясность» или практику «Счёт дыхания» (5 минут), чтобы
  мягко собрать внимание.
- **EN — title:** For a clearer head
- **EN — text:** The intellectual curve on the biorhythm chart is lower
  than usual right now — just an observation, not a verdict on your focus.
  Worth trying a tea from the "Focus and clarity" category, or the "Breath
  counting" practice (5 min), to gently gather your attention.

## P7 — Общий композит низкий, без явного провала по конкретному сигналу (фоллбек)

**Условие:** ни одно из P1–P6 не сработало, и `computeEnergy(...).value < 40`
**Зачем отдельный сценарий:** бывает день, когда понемногу ниже обычного
всё сразу, но ни один отдельный сигнал не проходит свой порог — молчать в
этом случае («показать дефолт как в хороший день») было бы неточно, но и
диагностировать нечем. Безопасный дефолт — лёгкая дыхательная практика,
без привязки к конкретной причине.
**Практика:** «Резонансное дыхание» (5 минут, уже описана в
`docs/content/практики.md`).
**Иконка:** `breathingCircle`

- **RU — заголовок:** Если сегодня тяжелее, чем обычно
- **RU — текст:** Сегодняшние показатели в целом немного ниже привычного —
  не повод что-то менять резко. Может помочь «Резонансное дыхание» (5
  минут): ровный темп, который мягко возвращает тело в равновесие.
- **EN — title:** If today feels a little heavier than usual
- **EN — text:** Today's numbers are a bit lower than usual across the
  board — no reason to change anything drastically. "Resonant breathing" (5
  min) might help: an even pace that gently brings the body back into
  balance.

## P8 — Дефолт (всё ровно, явного провала нет, или данных недостаточно)

Это не новый текст — это уже одобренные, существующие три карточки
`i18n/dictionaries/home.ts` (`focus1/focus2/focus3`), без изменений:
«Мягкий старт» (иконка `lotus`), «Планирование» (иконка `idea`),
«Пространство» (иконка `broom`). Используются как есть, в этом порядке,
для заполнения любых слотов, не закрытых P1–P7 — в том числе всех трёх
слотов, если профиль не даёт ни одного сигнала (нет даты рождения,
`computeEnergy` возвращает `null`) или ни один сигнал не проходит порог.

**Явно не меняется в рамках этой задачи:** содержание и формулировки
P8 — трогать их не входило в задачу, и они уже прошли свой собственный
путь правок (`HomeScreen.tsx`, комментарий 2026-08-27, «take 3»).
