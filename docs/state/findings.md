## Разногласия

**habit-designer vs wellbeing-safety, по находке №8 — закрыто 2026-09-05.**
Владелец решила: без памяти о выполненных практиках и без каких-либо
элементов геймификации (счётчиков, серий) для тем, связанных с состоянием.
Разногласие снято в пользу позиции `wellbeing-safety`. Находка №8 закрыта
без изменений в продукте.

## Что уже хорошо

- **Дыхательная практика — полностью законченный, работающий путь** от
  входа до выхода, с реальной физиологической техникой (квадратное
  дыхание) и без завышенных обещаний в тексте («помогает замедлиться и
  выровнять дыхание» — калиброванный тон, не режет глаз claims-reviewer).
- **Вопрос о поле сопровождён объяснением, зачем он нужен** («это
  необходимо, чтобы учитывать гормональные циклы...») — редкая для
  трекеров прозрачность о причине вопроса, снижает барьер недоверия из
  CJM напрямую.
- **«Пропустить онбординг» и «Заполнить позже» присутствуют почти на
  каждом шаге** — верная забота о том, чтобы не заставлять доводить
  длинную анкету до конца, прямое противоядие CJM-барьеру «формы, которые
  просят слишком много».
- **Инженерная гигиена необычно высокая для этой стадии**: код сам
  документирует происхождение почти каждого решения (комментарии в
  HomeScreen/CareScreen/BreathingSessionScreen объясняют, почему принято
  именно так) — облегчает любой будущий аудит и передачу другому
  разработчику.
- **Тон текста в целом выдержан аккуратно** за пределами отмеченных
  находок — нет давящих, обвиняющих или директивно-медицинских
  формулировок в остальных местах.

## Разбор с владельцем и ментором (2026-09-05)

- **№1, №2, №12, №15 — отклонены.** №1/№2: экраны, которых касается
  находка, владелец сознательно ещё не прорабатывала — преждевременно.
  №12/№15: не согласны с находкой по существу.
- **№3, №9 — исправлено в тот же день.** Все 9 текстов дня в

  теперь атрибутируется графику биоритмов («биоритм сегодня...», «судя

  графика с самочувствием — через мягкую рамку («может быть», «есть
  шанс»), не утверждение.
- **№4 — отложено.** Актуально станет, когда появятся сценарии для
  разных состояний (сейчас проработан только «низкий ресурс»). На

- **№7 — владелец не согласна с посылом «онбординг слишком длинный»**

## Что требует решения владельца продукта

   технической грамотности.
