## Провенанс и статус

Сценарии **реконструированы**, не написаны владельцем как спека:
- Онбординг, чай, статьи (список), аналитика — из вайрфреймов
  (`Вайрфреймы/`), эти экраны ещё не построены в коде.
- **Home, Care, дыхательная практика — из построенного кода `app/`**
  (это основной законченный сценарий, над которым сейчас идёт работа для
  портфолио). Вайрфреймы для этих трёх экранов устарели — код разошёлся
  с ними в заголовках, составе плиток, наличии колец-процентов и т.д.;
  расхождения явно отмечены в файлах 02–04.

Отсутствие экрана (вход, дневник, профиль, плееры, детальная аналитика,
пустые/ошибочные состояния, возврат после перерыва) отмечено как «экран
не найден/не построен» — **ожидаемо на этом этапе, не находка**. Роль
может рекомендовать добавить экран только если это критично для уже
существующего сценария, не как общее «доделайте всё».

Разделы «Наблюдения для аудита» в каждом файле — фактические замечания
для ролей, **не находки**. Находки формулирует команда по форме из
`docs/audit-contracts.md`.

Астрологическая и синтез-ветки в этот разбор не входят.
