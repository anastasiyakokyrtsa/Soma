## Провенанс и статус

Сценарии **реконструированы из вайрфреймов**, а не написаны владельцем как
спека. Где вайрфреймов нет (вход/регистрация, дневник, профиль, плеер,
уведомления, пустые/ошибочные состояния, возврат после перерыва), это
отмечено как «экран не найден» — не как готовое решение.

Разделы «Наблюдения для аудита» в каждом файле — фактические замечания
для ролей, **не находки**. Находки формулирует команда по форме из
`docs/audit-contracts.md`.

Астрологическая и синтез-ветки в этот разбор не входят.
