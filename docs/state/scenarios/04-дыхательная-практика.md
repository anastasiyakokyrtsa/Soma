# Сценарий: Дыхательная практика

**Источник — построенные экраны `app/screens/BreathingInfoScreen.tsx`,
`BreathingSessionScreen.tsx`, `BreathingCompleteScreen.tsx`, а не WF
25–28.** Это самый законченный сценарий в приложении — полностью
работает на устройстве. Расхождения с вайрфреймом отмечены явно.

## Шаги

### 1. Инфо (`BreathingInfoScreen`, WF 25)
- Крестик закрытия слева сверху → назад на Care.
- Орб в состоянии покоя (тот же компонент, что и в сессии, просто без
  анимации) — не отдельная статичная картинка.
- Карточка снизу: «Дыхание для возвращения в тело», **«2 минуты»**
  (округлено для читаемости; реальная длительность 1 мин 36 сек — 6
  циклов × 16 сек), описание — совпадает с вайрфреймом.
- Кнопка «Я готов» → сессия.

### 2. Сессия (`BreathingSessionScreen`, WF 26/27)
- Это **дыхание по квадрату** (box breathing): 4 фазы на цикл — Вдох /
  Задержка / Выдох / Задержка, **6 полных циклов** подряд (не одна фаза
  на весь показ, как выглядит на статичном вайрфрейме).
- Орб пульсирует по фазам, инструкция и тайминг под ним меняются вместе
  с фазой.
- Управление: закладка (сохранить), пауза/плей (по центру), лайк —
  **симметричный ряд из 3 кнопок**. Кнопка звука из вайрфрейма **снята
  осознанно**: в приложении вообще нет звукового движка (audio playback),
  так что регулятор звука без звука был бы фиктивным элементом.
- Прогресс — полоса внизу экрана (в вайрфрейме прогресса не было видно).
- Завершение автоматическое по достижении 6 циклов, не по кнопке.

### 3. Завершение (`BreathingCompleteScreen`, WF 28)
- Галочка в круге с ореолом, «Поздравляем! Ты выполнил практику» —
  совпадает с вайрфреймом.
- Кнопка «К другим дыхательным практикам» **активна**, но пока временно
  ведёт обратно на таб Care (список практик ещё не построен) — не
  заглушка «в никуда», а осознанная временная цель.

## Вход
- С экрана Care → плитка «Дыхание».

## Выход
- Успех → экран завершения → «К другим дыхательным практикам» (сейчас
  = Care).
- Прерывание: крестик на инфо-экране, стрелка назад во время сессии —
  оба явно ведут `goBack()`, прогресс цикла не сохраняется (при повторном
  входе счётчик обнуляется).

## Наблюдения для аудита (не находки)
- Единственная практика с реальным одним вариантом контента — нет выбора
  длительности/интенсивности, нет альтернативных дыхательных техник.
- Автозавершение по достижении цикла — нет способа продлить сессию, если
  хочется подышать дольше.
- Отсутствие звука — сознательное решение по нынешним техническим
  ограничениям (нет audio-движка), не забыли; но с точки зрения ценности
  практики (многие дыхательные приложения ведут голосом/тоном) это можно
  зафиксировать как открытый вопрос для tech-lead/product-lead, не как
  дефект.
