# Сценарий: Дыхательная практика

Источник: WF 25 (Info), 26–27 (сессия), 28 (завершение). Это единственная
практика, полностью представленная в вайрфреймах, и она построена
в приложении (`app/`, см. память project-app-development).

## Шаги

### 1. Инфо (WF 25)
- Крестик закрытия (×) в левом верхнем углу.
- Круг-орб на фоне (статичный, с подписью «Вдыхай»).
- Карточка снизу: заголовок «Дыхание для возвращения в тело», «3 минуты»,
  описание «Эта практика помогает замедлиться и выровнять дыхание.
  Подходит, если внутри есть напряжение или усталость.»
- Кнопка «Я готов» → сессия.

### 2. Сессия (WF 26, 27)
- Стрелка «назад» (‹) в левом верхнем углу.
- Дышащий орб: внешний круг + внутренний, пульсируют в такт дыханию,
  подпись в центре меняется: «Вдыхай» / (выдох).
- Инструкция под орбом: «Вдыхай через нос 4 секунды» (WF 26) /
  «Вдыхай через нос 2 секунды» (WF 27) — тайминги меняются по фазам.
- Панель управления: ♡ (сохранить в избранное), ⏸ пауза/плей,
  🔊 звук/громкость.
- Прогресс сессии — в приложении добавлен нижний прогресс-бар и счётчик
  повторов (см. память); в вайрфреймах прогресс не показан.

### 3. Завершение (WF 28)
- Крупная галочка в круге.
- «Поздравляем! Ты выполнил практику».
- Кнопка «К другим дыхательным практикам» (в приложении — временно ведёт
  назад на таб «Забота»).

## Вход
- С экрана «Забота» → карточка «Снизить внутреннее напряжение» (Дыхание).
- Из чипа «Дыхание» в «Восстанови ресурс».
- Предположительно из списка дыхательных практик (экран списка не найден).

## Выход
- Успех → экран завершения → «К другим дыхательным практикам».
- Прерывание: × на инфо-экране, ‹ во время сессии — куда возвращает
  и сохраняется ли прогресс, из вайрфреймов неясно.
- Пауза — состояние паузы (в приложении доводилось отдельно).

## Наблюдения для аудита (не находки)
- Нет экрана-списка дыхательных практик, хотя кнопка завершения ведёт
  «к другим».
- Что происходит при входящем звонке / сворачивании во время сессии.
- Ведётся ли звук практики (голос, фон) — иконка громкости есть,
  аудио-контент не описан.
- «Ты выполнил» — родовая форма в тексте завершения.
