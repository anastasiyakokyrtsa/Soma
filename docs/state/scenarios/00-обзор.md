# Обзор продукта и сценариев

Собрано из вайрфреймов (`Вайрфреймы/`, 38 экранов), user flow, CJM и job
stories (`Claude AI/v1/База для проекта/`), концепта «Внутренний космос»
и построенной части приложения (`app/`). Это описание того, **что есть**,
без оценки — оценка за ролями аудита.

## Приоритет: один законченный сценарий, не всё приложение

**Владелец продукта сознательно строит не все экраны сразу.** Сначала
доводится до конца один сквозной сценарий (онбординг → Home → Care →
дыхательная практика — целиком, для портфолио), и только потом остальное
приложение достраивается вширь. Это значит:

- Экраны, которые уже построены в коде (`app/`), — **основной источник
  правды**, вайрфреймы для них устарели там, где расходятся (см. пометки
  в файлах сценариев ниже).
- Отсутствие экрана (дневник, профиль, плееры, аналитика, чайная
  церемония и т.д.) — это **ожидаемое состояние текущего этапа, не
  находка сама по себе**. Аудит и роли работают с текущим сценарием как
  он есть; предлагать добавить недостающий экран — можно, но только если
  это критично для того, что уже есть (например: без этого нельзя пройти
  уже существующий путь, или это блокер безопасности/доверия), а не
  потому что «хорошо бы всё доделать».
- Полный охват всего приложения — следующий, более поздний этап.

## Что за приложение

Soma — мобильное приложение самонаблюдения. Ядро — единая оценка состояния
на сегодня («энергия дня»), собранная из нескольких источников, которые
вводит человек:
- классические биоритмы от даты рождения (физический / эмоциональный /
  интеллектуальный циклы);
- график и качество сна;
- менструальный цикл (для женщин);
- фазы Луны и солнечная активность (дополнительный слой).
Это приложение позволяет отслеживать свои состояния, фиксировать их, находить своим состояниям и настроениям объяснение, видеть паттерны, получать рекомендации как улучшить состояние или как избежать каких то негативных моментов в будущем.

На основе состояния приложение предлагает практики регуляции: дыхание,
чаи, медитации, звуки природы, музыку, сказки, статьи, чек-листы.

Разбираемая ветка — **научно-практическая** (в онбординге выбор из трёх:
научно-практический / астрологический / синтез). Не смешивать контент
веток: в научной ветке нет натальных карт, транзитов, таро.

Тональность (концепт «Внутренний космос»): «Ты — система. Изучай её.»
Тёмные фоны, светящиеся акценты, холодная палитра. Ощущение —
концентрация и вовлечённость, не расслабление.

## Модель навигации

Нижний бар (появляется после онбординга), наблюдаемые иконки:
1. **Главный** (дом) — Home
2. **Забота** (ладонь) — экран «Поддержка твоего состояния сегодня»
   (в вайрфреймах называется «How to do better»)
3. **+** (центр) — добавить запись / отметку (экран не найден в вайрфреймах)
4. **Дневник** (перо) — экран не найден в вайрфреймах
5. **Статистика** (лупа/график) — Аналитика

Профиль открывается по аватару в правом верхнем углу Home (экран не найден).

## Что НЕ представлено ни в коде, ни в вайрфреймах (наблюдения, не находки)

Ожидаемо на текущем этапе (см. «Приоритет» выше) — не поднимать как
проблему саму по себе, только если что-то из этого критично для уже
существующего сценария:
В принципе попутно можешь высказывать свои мысли и по несуществующим сценариям, но только нужно это как то обособленно обозначить, чтобы было понятно - тут речь про полный сценарий

- Экран входа/регистрации («Войти», «есть аккаунт») — во всех точках заглушка
- Ветка «Пропустить онбординг» — куда ведёт, что показывает Home без данных
Если нажимаю в приложении Пропустить онбординг, то соответственно попадаю сразу на главный экран, но он будет выглядеть конечно по другому поскольку нет вообще никаких данных на основе которых можно собрать первую статистику и рекомендации. Надо подумать как будет выглядеть этот экран.
- Ветки «Заполнить позже» на шагах профиля — состояние Home с частичными данными
- Экран «+» (добавление записи) и экран «Дневник»
- Экран профиля и настроек (смена подхода, визуального стиля, данные)
- Экран самой чайной церемонии (после «Начать чайную церемонию»)
- Плеер звуков природы / музыки, экран медитаций, экран сказок
- Уведомления (push о рекомендации, напоминания)
- Состояния: пустое, загрузка, ошибка, оффлайн, отказ в разрешениях
- Возврат после долгого перерыва
- Экран подписки / пейволл
- Детальная аналитика (Сон, Состояния, Луна, Солнце, Паттерны)
- Астрологическая и синтез-ветки (за рамками этого разбора)
