# Сценарий: Аналитика (Статистика)

Источник: WF 37 (галерея), 38 (детальный экран биоритмов).

## Шаги

### 1. Галерея данных (WF 37)
- Заголовок «Аналитика».
- Сетка 2×3 карточек: Биоритмы, Сон, Состояния, Луна, Солнце, Паттерны.
- Нижний бар виден (иконка «Статистика» активна). Центр бара — «+».
- Тап по карточке → детальный экран.

### 2. Детальный экран — Биоритмы (WF 38)
- Верх: ← «Вернуться в галерею данных», «Биоритмы (i)», иконка календаря.
- График 3 синусоид (шкала дат 10–18, сегодня 14).
- Переключатель периода: **День / Неделя / Месяц**.
- 3 кольца с процентами: Физиология 49,8%, Эмоции −96,3%, Интеллект 68,1%.
- Общая интерпретация: «Сегодня ваше состояние неравномерно: ум работает
  ясно и стабильно, физический ресурс — на среднем уровне, а эмоциональный
  фон находится в чувствительной фазе…»
- 3 блока по уровням, у каждого: описание фазы + два списка «полезно» /
  «не рекомендуется»:
  - **Физический уровень** — полезно: прогулки, растяжка, спокойный ритм;
    не рекомендуется: интенсивные тренировки, недосып, перегрузки.
  - **Эмоциональный уровень** — полезно: дневник, рефлексия, личные
    границы; не рекомендуется: важные решения, конфликты, самокритика.
  - **Интеллектуальный уровень** — полезно: планирование, учёба, чтение,
    структура; не рекомендуется: многозадачность, эмоциональные разговоры,
    работа на износ.

### 3. Другие детальные экраны
Сон, Состояния, Луна, Солнце, Паттерны — экраны не найдены в вайрфреймах.
«Паттерны» = взаимосвязи между источниками («сон ↔ энергия» и т.п.),
по job stories и CJM это ключевая ожидаемая ценность.

## Вход
- Иконка «Статистика» в нижнем баре.
- «Подробнее» у биоритмов на Home → детальный экран биоритмов.

## Выход
- ← в галерею.
- Календарь / переключатель периода — исторические данные.

## Наблюдения для аудита (не находки)
- Отрицательный процент «Эмоции −96,3%» — шкала и её читаемость.
- «Паттерны» — центральная ценность продукта (по исследованиям), но
  единственный проработанный детальный экран — биоритмы, самый спорный
  с научной стороны.
- Что показывает аналитика при 1 дне данных против года (масштаб графика,
  навигация по датам).
- Списки «полезно / не рекомендуется» — директивность формулировок, зона
  wellbeing-safety и claims-reviewer.
